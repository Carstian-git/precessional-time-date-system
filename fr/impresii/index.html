Impressions

Qu'est-ce qui vous a plu ? Qu'est-ce qui n'était pas clair ? Que changeriez-vous ? Écrivez ci-dessous une impression sur le site, les outils ou le livre. Les commentaires restent sur cette page.

Comment ça marche

  • Les commentaires s'écrivent avec un compte GitHub (gratuit). Si vous n'en avez pas, vous pouvez en créer un en quelques minutes sur github.com.
  • Les commentaires sont publics et apparaissent sous le nom du compte GitHub.
  • Merci d'être courtois et de ne pas publier de données personnelles (téléphone, adresse) ni de publicité. Les commentaires inappropriés peuvent être supprimés.
  • Si vous avez trouvé une erreur dans le site ou dans le livre, indiquez la page ou le chapitre, afin que nous puissions la corriger.

Pas de compte GitHub ?

Vous pouvez écrire librement, sans compte, dans un formulaire à un seul champ. Le message parvient à l'auteur ; certaines impressions pourront être publiées ensuite sur cette page.

Écrire une impression, sans compte

Confidentialité

Les commentaires sont hébergés par GitHub (dans la section Discussions du dépôt du site) et affichés avec Giscus (giscus.app). Celui qui commente publie sous son propre compte GitHub, les règles de GitHub s'appliquent donc aussi. Nous n'utilisons pas les commentaires à d'autres fins. Vous pouvez supprimer votre propre commentaire directement sur GitHub. Le formulaire est hébergé par Google Forms ; le nom est facultatif et aucune adresse e-mail n'est demandée.

Temps précessionnel humain · Calendrier précessionnel humain

Un système personnel de mesure du temps, indépendant des dogmes : l'heure comme angle, l'année ancrée au solstice, les ères selon la précession. Il ne remplace ni l'heure civile ni les normes officielles.
