Impressions

What did you like? What was unclear? What would you change? Write an impression below about the site, the tools or the book. Comments stay on this page.

How it works

  • Comments are written with a GitHub account (free). If you do not have one, you can create it in a few minutes at github.com.
  • Comments are public and appear under the name of the GitHub account.
  • Please be polite and do not post personal data (phone, address) or ads. Inappropriate comments may be deleted.
  • If you found a mistake in the site or in the book, say which page or chapter, so that we can correct it.

No GitHub account?

You can write freely, without an account, in a form with a single field. The message goes to the author; some impressions may later be published on this page.

Write an impression, no account needed

From our readers' impressions

Impressions are chosen by the author. They appear with the name given in the form, if you wrote one.

Privacy

Comments are hosted by GitHub (in the Discussions section of the site repository) and displayed with Giscus (giscus.app). Whoever comments publishes under their own GitHub account, so GitHub's rules also apply. We do not use the comments for any other purpose. You can delete your own comment directly on GitHub. The form is hosted by Google Forms; the name is optional and no e-mail is requested.

Human precessional time · Human precessional calendar

A personal, dogma-independent way of measuring time: the hour as an angle, the year anchored to the solstice, eras from precession. It does not replace civil time or official standards.
